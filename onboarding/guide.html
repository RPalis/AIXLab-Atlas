Guardrails: read once, apply always

  • G1Practice only in a folder called atlas-practice. Never point a skill at a client project, a production repo or real research.
  • G2Never paste passwords, API keys, tokens, client names or real user data into any chat.
  • G3Keep Claude on its default "ask before editing". Do not switch on bypass or auto-accept.
  • G4Plan first. A skill must show you a plan before writing a file. If it does not, say "stop, show me your plan first".
  • G5No invented evidence. A persona, quote or number must trace to a source, or the skill must say "unknown". Treat untagged claims as invented.
  • G6Human review. Read each output before running the next skill.
  • G7Stop and tell the observer if a file appears outside atlas-practice, Claude asks for a password or token, or you are stuck for more than 5 minutes.

2. Install the skills

macOS (checked)

  1. Open Terminal: press Cmd+Space, type Terminal, press Enter.
  2. Type cd (with a space after it), drag the unzipped folder from Finder onto the Terminal window, press Enter.
  3. Run the installer: 
    ./install.sh --claude --no-open
    If you see "permission denied", run chmod +x install.sh and try again.
  4. CheckThe last lines say Symlinked 30 skills into Claude Code and Successfully installed 30 skills!. If the number is not 30, stop and report it.

What this did: copied the skills to ~/.agents/skills and linked each into ~/.claude/skills. Nothing else. The file ~/.agents/skills/.ux-atlas.manifest lists exactly what was installed, in case you want to remove it later.

Windows (not yet verified)

The installer is a bash script that uses symlinks, so it needs a Linux-style shell.

Option 1, WSL (recommended): install "Ubuntu" from the Microsoft Store, open it, unzip the files inside it, then follow the macOS steps. Claude Code must be installed in the same environment.

Option 2, copy by hand: copy all 30 folders from the unzipped skills folder into C:\Users\<you>\.claude\skills (create it if missing). Check that each folder contains a file named SKILL.md.

5. Do you have a design system?

Advice, never a blocker. Claude will ask; you can say "skip". Output built without a real system is labelled so nobody mistakes placeholder values for real ones.

A. Tokens already in code

An index.css with colour and spacing variables.

Run styleguide and ask it to audit and document what exists.

Result: a DESIGN.md generated from your real tokens.

B. A brand, no system

A brand guide PDF, a live site, or hex codes you can type.

Run styleguide in forge mode. If two sources disagree, it must ask which wins.

Result: tokens cast from your brand, each value traced to a source.

C. A Figma library only

Needs the Figma connector set up.

Run figma in import mode, then sync to keep tokens aligned.

Result: code that follows your library.

D. Nothing yet

Most first runs land here.

Run styleguide in default mode.

Result: a placeholder palette. Every screen is labelled "placeholder tokens". Come back to B later.

  1. CheckAsk Claude: "Which of these values came from my sources and which did you choose?" A correct answer separates the two.

6. Finished properly?

A skill is done only when all three are true:

  • You saw a plan before any file was written.
  • Every claim is tagged evidenced, inferred or assumed, or is listed under unknowns.
  • You reviewed the output and said accept, reject or unsure.

If one is missing, report it even if the output looks good. Then fill in the feedback form your observer gave you (onboarding/FEEDBACK-FORM.md in the repository).

If something goes wrong

Installer says "permission denied"

The file is not marked executable. Run chmod +x install.sh, then the installer again.

"command not found" or "bad interpreter"

Windows line endings, or not a bash shell. Use WSL, or copy the folders by hand.

Typing / shows no AIX Lab-Atlas skills

Claude Code started before the install. Quit it fully and reopen. Still nothing: re-download the ZIP and run the installer again, and check the count says 30.

/help shows a different help screen

The built-in command takes priority. Say "Use the AIX Lab-Atlas help skill".

A skill starts writing before showing a plan

Say "stop, show me your plan first". Then report which skill it was.

Claude asks for a password or token

It should not. Do not enter it. Stop and tell the observer.

Chat track: skill uploaded but ignored

Check that it is switched on, and that the ZIP holds the skill folder itself rather than loose files.

A skill mentions another skill you cannot find

Note the name and report it. It is a stale reference.
