# Human review checklist

Attach this to every deliverable. The output is a **first draft, not final analysis** until a
human has worked through it.

## Before sharing this work
- [ ] **Verify every important finding** against its source transcript.
- [ ] **Remove anything marked `Not Verified`** (or move it to an open-questions list).
- [ ] **Resolve every ⚠️** — confirm the quote is verbatim or drop it.
- [ ] **Add screenshots and links** where useful.
- [ ] **Prioritise opportunities based on business goals**, not just frequency.
- [ ] **Refine the format** — e.g. "From this Excel, can I create a presentation?" Convert as
      needed (the skill can regenerate in .docx / .xlsx / .pptx).
- [ ] Confirm no confidence tags, interview numbers, or weak-signal flags were lost in formatting.
- [ ] Run the prose through `humanizer` if available — no AI-isms, no em dashes.

## What's next (feed the design-process working set)
- Feed the analysis and any audience comments back into the repo / task folder.
- Keep the prompts, the `.md` fidelity file, the chat-history context, and the tooling **together
  in the same task folder** — this is your reusable design-process working set.
- Reuse these outputs in: **persona drafts · journey maps · problem statements · user stories.**
