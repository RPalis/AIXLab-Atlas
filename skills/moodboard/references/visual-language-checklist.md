# Reading a Visual Reference

What to extract from one reference screenshot (or rendered URL) — six
dimensions, not a literal color/font dump. The point is the *pattern*, not a
pixel-accurate copy: two references can use completely different hex values
and still share the same visual language, and two references can share a
palette while feeling nothing alike.

| Dimension | What to look for, not just what's technically present |
|---|---|
| **Color relationships** | Not the literal hex values — how color is *used*: mostly-neutral with one accent, multi-hue and saturated, monochrome, high-contrast vs. low-contrast. A palette read as swatches misses this; read it as "where does the eye land first, and why." |
| **Typography personality** | Serif vs. sans, weight (light/regular/bold as the default voice, not just headers), scale contrast (subtle size steps vs. dramatic jumps), letter-spacing, whether type itself carries brand character or stays neutral. |
| **Spacing density** | Generous whitespace vs. dense/information-rich, consistent rhythm vs. varied, how much breathing room around interactive elements. |
| **Shape language** | Corner radius (sharp/soft/pill), border usage (hairline dividers vs. none vs. heavy), overall geometric vs. organic feel. |
| **Elevation & depth** | Flat design vs. heavy shadows, how layering/hierarchy is communicated (color, size, shadow, or position alone), motion/transition cues if visible. |
| **Overall character** | 2-4 adjectives that describe the *feeling*, not the mechanics — "minimal," "playful," "editorial," "technical/dense," "warm," "clinical." This is the summary the other five dimensions should add up to, not an independent guess. |

**Don't invent what isn't visible.** A reference that doesn't show an error
state, a form, or a dense data view doesn't get a guessed opinion on how it
would handle one — note what the reference actually shows and stay there.

**A reference is a data point, not a verdict.** One screenshot never
determines a whole direction on its own — that's what averaging across
multiple references (`moodboard`) or generating distinct candidate directions
(`restyle`) is for.
